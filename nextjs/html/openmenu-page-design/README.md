# Open Menu: page designs

Standalone HTML mockups (static, open in any browser). Fluid layouts: resize the window to check mobile and desktop.

Brand: amber tile #D97706, primary buttons #B45309 (deeper amber for text contrast), ink #1C1917, background #FAF8F5, headings in Bricolage Grotesque (Google Fonts, loaded by link).

Pages: 01 landing, 02 public menu (phone), 03 selection/calculator (phone), 04 owner create shop, 05 owner overview (with pending/rejected/suspended states), 06 owner menu manager, 07 admin approval queue, 08 admin shop review.

The same boards live in the Design canvas "Open Menu Pages".
